## Web and Desktop Preview

[Открыть веб-версию по HTTPS](https://bridge.82-26-151-8.sslip.io)

Для Mac M4 выбирайте файл с окончанием `mac-arm64.dmg`. Готовые установщики также доступны для Intel Mac, Windows x64 и Linux x64. Исходники собирать не нужно.

**Подпись:** в этой сборке ещё нет Developer ID/notarization для macOS и сертификата Windows. Возможна блокировка Gatekeeper/предупреждение SmartScreen. Полностью беспрепятственный первый запуск desktop пока не гарантирован. Для использования без установки доступна веб-версия в Chrome/Edge.

### Изменения

- Взрослый маршрут из десяти занятий: узнавание, паттерны, новые этюды и чтение вперёд.
- Начало без автоматически падающих нот. Явный старт, конечное занятие, пауза и результат.
- Равная ширина начальных линий-полос и белых промежутков, общая геометрия с клавиатурой, настоящие музыкальные ключи.
- Локальная обработка USB-MIDI без сервера и без программного звука.
- Ошибки, пропуски, реакция, атака и отпускание; отдельные новые/повторные/пробные попытки.
- Сохранение истории, проверяемый JSON-импорт и экспорт.

Это предварительная версия взрослого ядра, не весь курс из методологии. Нет полифонии, альтераций, оценки педали и физических замеров задержки на Kawai CA701/M4. Веб и desktop не синхронизируют прогресс автоматически. Подробнее в README.
