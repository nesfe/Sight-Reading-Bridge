## 0.3.0 · MusicXML и переход к обычной нотации

[Открыть веб-версию по HTTPS](https://bridge.82-26-151-8.sslip.io)

Для Mac M4 выбирайте файл с окончанием `mac-arm64.dmg`. Готовые установщики также доступны для Intel Mac, Windows x64 и Linux x64. Исходники собирать не нужно.

**Подпись:** в этой сборке ещё нет Developer ID/notarization для macOS и сертификата Windows. Возможна блокировка Gatekeeper/предупреждение SmartScreen. Полностью беспрепятственный первый запуск desktop пока не гарантирован. Для использования без установки доступна веб-версия в Chrome/Edge.

### Изменения

- C4: тонкая локальная добавочная черта вместо широкой плашки.
- Три явных вида учебного стана: вертикальные равные полосы, горизонтальные равные полосы, обычная нотация. Отдельные уроки снятия подписей и перехода к горизонтали; всего 12 занятий.
- Локальная библиотека MusicXML (.musicxml/.xml) и MXL: сохранение, удаление, масштабирование и экспорт.
- Полная импортированная партитура с аккордами, паузами, альтерациями и лигами. Просмотр в обычном и горизонтальном полосовом виде.
- Пошаговая USB-MIDI-проверка высоты импортированной партии: все станы или выбранный стан, аккорды, повторные атаки, связанные ноты. Обратная связь без сервера, программного звука и полной перерисовки партитуры на каждое нажатие.

Ограничения: для импортированных файлов пока нет вертикального вида, оценки ритма/длительности/педали и сохранения результатов в историю курса. Повторы не исполняются, форшлаги пропускаются. MusicXML timewise, MIDI-файлы и PDF не импортируются. Генерируемые занятия пока одноголосные. Анимированного поворота между видами нет. Физическая задержка на Kawai CA701/M4 не измерялась. Подробнее в README.
